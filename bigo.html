📈 Analisis Big O

Halaman ini menjelaskan kompleksitas waktu (Time Complexity) dari setiap algoritma yang digunakan pada aplikasi Mental Health Tracker.

Fitur Algoritma Big O Penjelasan
💾 Simpan Mood Array Push O(1) Menambahkan data baru ke akhir array.
📖 Tampilkan Riwayat Traversal O(n) Membaca seluruh data mood satu per satu.
🔍 Cari Mood Linear Search O(n) Mencari data secara berurutan hingga ditemukan.
⬆ Urutkan Stress Bubble Sort O(n²) Membandingkan setiap elemen dengan elemen lainnya.
🕸 Graph Aktivitas Adjacency List O(V + E) Menyimpan hubungan antar simpul (Vertex dan Edge).
🟢 BFS Breadth First Search O(V + E) Mengunjungi semua simpul berdasarkan level.
🔴 DFS Depth First Search O(V + E) Menelusuri simpul hingga cabang terdalam.

📚 Kesimpulan

O(1)

Operasi sangat cepat karena tidak bergantung pada jumlah data.

O(n)

Waktu eksekusi bertambah seiring bertambahnya jumlah data.

O(n²)

Digunakan pada Bubble Sort karena terdapat dua perulangan (nested loop).

O(V + E)

Digunakan pada Graph, BFS, dan DFS karena mengunjungi seluruh simpul (Vertex) dan hubungan (Edge).
